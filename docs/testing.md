# SmartClinic+ Testing

## Automated tests
The test suite covers:
- Login page loading
- Protected dashboard access
- Invalid login
- Appointment double-booking constraint
- Role-based queue access

## Manual tests
- Valid login for each demo role
- Book an appointment
- Attempt the same doctor/time slot twice
- Check in to the queue
- Call and complete a queue entry
- Open an EHR
- Add a lab result
- Issue a prescription as a doctor
- Create and complete a staff task
- Review notifications
- Review analytics

Actual pass/fail results should be recorded after the tests are run; this document does not invent execution results.
